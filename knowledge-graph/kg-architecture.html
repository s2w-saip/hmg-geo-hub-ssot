주는 것 — KG DB, 판마다 한 벌

무엇쓰는 곳비고
판 ID · 지금 판파이프라인 회차 버전 정보(엔티티 카탈로그), 분석 추출 규칙 버전판은 지우지 않는다. 지금 판은 포인터 한 줄이 가리킨다
엔티티: 브랜드 · 차종 · 기업 · 국가, 자사 · 경쟁 표시분석 엔티티 → 브랜드 매핑사람이 확인한 것과 초안을 가른다
이름 · 별칭: 언어 · 종류 · 대조 조건분석 엔티티 찾기사람이 확인한 것과 초안을 가른다
관계: 차종 → 브랜드, 브랜드 → 소유 기업 · 출신 국가, 기업 → 모회사 · 본사 국가분석 엔티티 → 브랜드 매핑소유 · 모회사 · 본사는 시작 · 끝이 있다
엔티티 아님: 늘 아님 · 애매한 이름분석 애매한 이름애매한 이름은 문맥으로 판단한다

KG DB는 읽기 계정으로 읽는다. 접속 정보는 따로 전달한다. 테이블 · 필드는 지식그래프 저장소의 poc/db/data-dictionary.md에 있다.

다른 파트와 정할 것

  1. 연결 방식 · 새 판 알림: KG DB를 바로 읽을지, 판 파일을 받을지. 새 판을 어떻게 알릴지.
  2. 버전 표기: KG의 버전은 판 ID다. 분석의 추출 규칙 버전 표는 KG를 git으로 적었다.
  3. 기준정보의 원본: 자사 브랜드 · 브랜드 엔티티 역할 · 인용 출처 분류를 서비스 DB와 KG 중 어디에 둘지. 서비스 입력 계약은 서비스 DB, 파이프라인 그림은 KB로 적었다. KG 판에는 자사 · 경쟁 표시가 있고, 인용 출처 분류 규칙은 없다.
  4. 응답 원문을 읽는 곳: 응답 원문(Bronze)과 분석 입력 준비 중 어디서 읽을지.

용어

용어뜻
지식그래프(KG)자동차 엔티티(브랜드 · 차종 · 기업 · 국가)와 그 이름 · 별칭 · 관계. 이 파트의 이름이기도 하다
기준 판(판)사람이 확인한 엔티티 · 별칭 · 관계(지식베이스)를 버전으로 낸 한 벌. 판 ID 예: kb-0.5-20261104T070459Z
엔티티 사전추출이 대조하는 이름 · 별칭 목록. LLM이 만든 초안을 포함하고, 발행한 판으로 갱신한다
사전 대조표기를 정규화해 엔티티 사전의 별칭과 맞추는 단계. 글자 비교다
초안기계가 쓰고 사람이 아직 확인하지 않은 엔티티 · 별칭 · 관계
자동 판정사람이 이미 정한 것과 같은 후보를 자동으로 판정한다. 자동 판정 표시를 남긴다
사람 검수(HITL)도메인 검수자가 검수 화면에서 새 엔티티 · 별칭 · 관계만 확인 · 교정 · 승인한다
골드셋사람 판정 모음. 추출 정확도를 재는 데 쓴다
KG DB판을 쌓는 PostgreSQL. 지식그래프 저장소에서는 결과 DB, 파이프라인 그림에서는 KB DB라 부른다
