# 지표 정의

서비스(BFF)가 정의하고 OBT 운영 스냅샷에서 계산하는 지표다. 지표 이름은 화면의 정식 이름(레거시 KPI)을 쓴다.

## 지표 변경

- 지표 변경(새 지표, 필터, 분모)은 서비스 안에서 끝난다.
- 지표 정의는 코드와 테스트로 남긴다. 정의 변경은 분석팀도 리뷰한다.
- 정의가 바뀌면 지표 정의 버전이 바뀐다. 사전 집계(Gold)와 캐시 DB는 이 버전을 함께 남긴다.

## 공통 조건

| 항목 | 정의 |
|---|---|
| 모니터링 답변 | 지표에 넣는 답변. 집계 자격이 있고 분석이 빠지지 않은 답변. ACR 측정은 셀마다 최신 반복 1회만 넣는다 |
| 인용 모니터링 답변 | 인용 지표에 넣는 답변. 모니터링 답변과 같되, 분석이 빠진 답변도 넣는다 |
| 대표 답변 | 회차 · 프롬프트 · 엔진 · 국가 · 언어 조합마다 1건 |
| 당사 | 계정 관점의 자사 브랜드 합. 기본은 Hyundai + Kia + Genesis |
| 회차 | 수집이 시작된 날짜로 구분한다. 주 1회 |
| Δ | 값이 있는 직전 회차 대비 차(비율은 pp). 기간을 고르면 바로 앞 같은 길이 기간 대비 |
| 권역 값 | 권역 안 국가의 분자 · 분모를 더해 다시 계산 |

## 언급

| 지표 | 분자 | 분모 | 비고 |
|---|---|---|---|
| AI 노출률 | 당사 브랜드가 1회 이상 언급된 답변 | 대표 답변 | |
| AI 점유율 | 당사 브랜드 언급 횟수 | 전체 브랜드 언급 횟수 | 한 답변 안 여러 번 언급 포함 |
| AI 우호도 | 당사 언급의 긍정 감성 | 당사 언급의 전체 감성(긍정 · 중립 · 부정 · 혼합) | 언급 단위 |
| AI 우선 노출도 | 당사 언급 순위 합 | 당사 브랜드가 1회 이상 언급된 답변 | 순위 = 당사보다 먼저 언급된 경쟁 브랜드 수 + 1. 비경쟁 · 노이즈 브랜드는 뺀다. 낮을수록 앞 |
| Top 3 노출 비율 | 당사 언급 순위가 3 이하인 답변 | 당사 브랜드가 1회 이상 언급된 답변 | 순위는 AI 우선 노출도와 같다 |
| 멘션 유형별 노출 | 그 언급 유형으로 당사가 나온 답변 | 모니터링 답변 | 언급 유형: 단순 언급 · 추천 · 비교 · 정의 · 최종 선택 |
| 경쟁사 대비 SOV | 당사 언급 횟수 | 언급 1위 경쟁사 언급 횟수 | N배로 표시(vs 그 경쟁사) |

경쟁사 값은 같은 정의를 그 브랜드로 계산한다.

## 인용

| 지표 | 분자 | 분모 | 비고 |
|---|---|---|---|
| AI 인용 점유율(global) | 출처 카테고리 공식 (HMG) 인용 횟수 | 전체 출처 인용 횟수 | 공식 (HMG) = HMG 3사 공식 사이트와 공식 소셜 계정 |
| AI 인용 점유율(website) | 자사 URL 인용 횟수 | 전체 출처 인용 횟수 | 자사 URL = 소유 URL(등록한 대표 주소와 하위 경로) |
| 인용 비중 | 그 출처 카테고리 인용 | 전체 인용 | 출처 카테고리별. 예: 공식 (HMG) 인용 비중, 딜러·마켓 인용 비중 |
| 자사 URL 인용률(website) | 자사 URL이 1회 이상 인용된 프롬프트 | 측정 프롬프트 | 프롬프트 단위 |
| 타겟 URL 인용률(website) | 그 프롬프트에 지정한 타겟 URL이 인용된 프롬프트 | 측정 프롬프트 | 다른 프롬프트의 타겟 인용은 뺀다 |
| AI 타겟 출처 인용률(website) | 당사 타깃 도메인이 인용된 답변 | 당사 도메인이 인용된 답변 | 답변 단위 |
| 공식(당사) URL 미인용 프롬프트 | 인용은 있지만 자사 URL 인용이 없는 프롬프트 | — | 개수 |
| 커버리지 | 그 출처를 인용한 답변 | 인용 모니터링 답변 | |

## ACR (AI 선택)

셀 = 프롬프트 × 엔진 × 국가. 반복 = 같은 셀을 여러 번 물은 것.

| 지표 | 분자 | 분모 |
|---|---|---|
| Top1 ACR(선택률) | 브랜드가 최종 1순위로 선택된 횟수 | 전체 반복 |
| 후보군 포함율 | 브랜드가 후보로 1회 이상 나온 셀 | 전체 셀 |
| 차종별 선택 전환율 | 후보군에 오른 차종이 최종 선택된 횟수 | 그 차종이 후보로 나온 셀의 반복 합 |
| 맞대결 | 당사 · 경쟁사가 함께 후보에 오른 반복 중 각자 선택된 횟수 | 함께 후보에 오른 반복 |
