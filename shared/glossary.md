# 용어

'화면 이름'은 레거시 · 리뉴얼 화면에 쓰인 이름이다. 같으면 비운다.

## 구조

| 용어 | 뜻 | 화면 이름 |
|---|---|---|
| 수집 | AI 엔진에 질의하고 응답을 받는 단계. 앤써(Scope) | |
| 추출 | 응답에서 읽어 낸 정보와 분류: 엔티티 → 브랜드 매핑, 감성, 언급 유형, 언급 순위 · 첫 언급 위치, 인용 URL · 출처 분류. 분석팀 | |
| 가공 | 추출 결과를 정의대로 집계해 지표를 계산하는 일: 분모 조건, 자사 여부 판정, 대표 답변 선정, 집계 기간, 계산식. 서비스(BFF) | |
| 서비스 제공 | 화면과 지표 API를 내는 단계. 서비스 | |
| 프롬프트·기준정보 원본 | 서비스 DB에 둔 프롬프트, 측정 설정, 수집 기준정보, 분석 기준정보. 서비스가 만들고 관리하며 Gold DB와 분리해 둔다 | |
| Bronze | 수집한 응답 원문 | |
| 분석 입력 준비 | 데이터 수급 안정성을 위해 Bronze를 통째로 복사해 둔 임시 DB. 파이프라인. 정본이 아니다 | |
| Silver · OBT | 추출 결과 테이블. 답변 1건 = 1행. 분석이 만들고 파이프라인(주) · 분석(부)이 관리한다 | |
| Gold | 사전 집계 테이블: 필터 없는 초기 화면의 지표 값. BFF가 계산해 저장한다 | |
| 캐시 DB | 필터 조회 결과를 다음 회차가 운영 반영될 때까지 두는 서비스 전용 DB. BFF가 만들어 저장한다. 정본이 아니다 | |
| 계약 1 · 계약 2 | Bronze(수집 → 분석) · Silver(분석 → 서비스) | |
| 스냅샷 | 파이프라인이 Silver에 한 번에 적재하는 단위. `loading` → `ready` → `public` → `retired` | |
| 운영 스냅샷 · 운영 반영 | 상태가 `public`인 스냅샷(회차마다 하나) · 스냅샷을 `public`으로 바꾸는 일 | |
| 운영 스냅샷 포인터 | 회차마다 운영 중인 스냅샷을 가리키는 한 행. 파이프라인이 한 트랜잭션으로 바꾼다 | |
| 매니페스트 | 적재 기록: 회차, 스냅샷 ID, 행 수, 추출 규칙 버전, 상태 | |
| 사전 집계 | 필터 없는 초기 화면 값을 회차마다 미리 전부 계산해 Gold에 두는 것. 늦거나 실패하면 그 값은 보여 주지 않는다 | |
| 조회 시점 집계 | 필터를 건 조회를 BFF가 OBT 운영 스냅샷에서 전부 세는 것. 결과는 조회 조건별로 캐시 DB에 둔다 | |
| 지표 정의 버전 | 지표 정의가 바뀌면 바뀌는 버전. 사전 집계와 캐시 DB가 함께 남긴다 | |
| 지표 API | 서비스가 지표를 내보내는 API. 모든 소비자가 BFF를 거친다 | |
| 수집 기준정보 | 수집에 필요한 기준정보: AI 엔진, 국가, 언어, 글로벌 키워드 카탈로그, 글로벌 소스 URL. 수집이 읽는다 | |
| 분석 기준정보 | 분석에 필요한 기준정보: 분류 체계, 자사 브랜드, 인용 출처 분류, 브랜드 엔티티 역할 등. 분석이 읽는다. 자사 정보는 Silver를 만들 때 자사 분류에 쓴다 | |
| 프롬프트·기준정보 API | 프롬프트·기준정보 원본(서비스 DB)을 읽는 API. 수집은 프롬프트 · 측정 설정 · 수집 기준정보, 분석은 분석 기준정보를 읽는다 | |

## 측정

| 용어 | 뜻 | 화면 이름 |
|---|---|---|
| 회차 | 수집이 시작된 날짜로 구분하는 측정 단위. 주 1회 | 측정 회차 |
| 표면 | 측정 묶음 | Global · Website · Project |
| 프롬프트 | AI 엔진에 묻는 질문 | |
| 카탈로그 · 분류 | 측정하는 프롬프트 목록 · 프롬프트 분류 경로 | Depth 1 ~ Depth 4 |
| 리스트 유형 | 카탈로그 목록의 종류 | 리스트 유형 · 리스트 타입 |
| 브랜드 포함 여부 | 프롬프트에 브랜드 이름이 있는지 | 브랜드 포함 · 브랜드 미포함 |
| 프롬프트 퍼널 | 프롬프트의 구매 여정 단계 | |
| 측정 종류 | 한 번 묻는 측정과, 같은 질문을 반복해 최종 선택을 보는 측정 | 단발 · ACR |
| AI 엔진 | 답하는 AI(ChatGPT, Gemini 등) | 측정 엔진(website) |
| 국가 | 측정 국가 | |
| 권역 | 국가를 묶은 지역 본부(RHQ) 단위. 필터와 계정 범위에 쓴다 | 권역 |
| 대륙 | 시장 표 · 지도에서 국가를 묶는 대륙 7개 | 권역(시장별 현황 표의 묶음 행) |
| website 측정 단위 | website 측정의 단위: 사이트 · 언어 · 기준 URL | |
| 측정 설정 | 측정할 브랜드 · 국가, website 측정 단위 · 기준 URL, AI 엔진, 측정 주기, ACR 반복 수, 소유 URL, 추적 URL, 추적 대상. 서비스 DB에 두고 사용자가 서비스에서 추가 · 조회 · 수정 · 삭제한다. 수집이 읽는다 | 프로젝트 설정 |
| 측정 주기 · ACR 반복 수 | 정기 측정 간격 · ACR 측정에서 셀마다 반복하는 횟수 | 측정 주기 |
| 추적 대상 | 프로젝트에서 추적하는 경쟁 브랜드 · 모델 | 추적 대상 |

## 답변 분석

| 용어 | 뜻 | 화면 이름 |
|---|---|---|
| 모니터링 답변 | 지표에 넣는 답변 | |
| 대표 답변 | 회차 · 프롬프트 · 엔진 · 국가 · 언어 조합마다 1건 | |
| 브랜드 엔티티 | 응답에 나온 이름(브랜드 · 차종 · 회사). 역할은 자사 · 경쟁사 · 제외 | 엔티티 |
| 엔티티 → 브랜드 매핑 · 모그룹 | 브랜드 엔티티를 표시 브랜드로 묶는 것 · 브랜드를 묶는 상위 그룹(예: Toyota 그룹) | |
| 당사 · 자사 | 계정 관점의 자사 브랜드 합. 기본 Hyundai + Kia + Genesis | 당사 |
| HMG 계열 | HMG 브랜드이지만 그 관점의 당사가 아닌 브랜드 | HMG 계열 |
| 경쟁사 | 당사 · HMG 계열이 아닌 브랜드 | |
| 비경쟁 · 노이즈 브랜드 | 순위와 경쟁 비교에서 빼는 브랜드 | |
| 언급 유형 | 브랜드가 나온 방식 | 멘션 유형: 단순 언급 · 추천 · 비교 · 정의 · 최종 선택 |
| 감성 | 브랜드 언급마다 매긴 감정. 언급 단위 | 감정 신호: 긍정 · 중립 · 부정 · 혼합 |
| 스탠스 | 답변 전체를 읽고 브랜드마다 매긴 태도 | 스탠스(태도) |
| 감성 밑줄 | 답변 문장 단위 감정 표시 | 감성 밑줄 |
| 언급 순위 | 답변 안에서 그 브랜드보다 먼저 언급된 경쟁 브랜드 수 + 1 | 경쟁 순위 |
| 첫 언급 위치 | 본문에서 처음 나온 순서 | |
| 분석 공백 | 분석이 빠진 답변. 모니터링 답변에서 뺀다 | |

## 인용

| 용어 | 뜻 | 화면 이름 |
|---|---|---|
| 인용 | 답변이 근거로 단 URL | |
| 출처 | 인용을 묶는 단위: 도메인 또는 소셜 계정 | |
| 출처 카테고리 | 출처의 종류 13개 | 공식 (HMG) · 공식 (경쟁사) · 딜러·마켓플레이스 · 자동차 미디어 · 뉴스·미디어 · 커뮤니티·포럼 · 소셜·영상 · 블로그·리뷰 · 위키·백과 · 정부·공공 · 권위(수상·인증) · 학술·연구 · 기타 |
| 출처 분류 | 출처에 카테고리를 붙이는 일. 정한 근거(분류 출처)는 6가지. 사람이 고친 것은 도메인 큐레이션 | 인용 출처 분류 |
| 공식 (HMG) | HMG 3사(현대 · 기아 · 제네시스) 공식 사이트와 공식 소셜 계정 | |
| 자사 URL | 측정 사이트의 등록 대표 주소와 하위 페이지 | 소유 URL(우리 사이트 범위) |
| 추적 URL | 성과를 볼 개별 페이지 | 추적 URL |
| 타겟 URL | 프롬프트마다 인용되길 바라는 지정 페이지(website) | |

## ACR

| 용어 | 뜻 | 화면 이름 |
|---|---|---|
| 셀 | 프롬프트 × 엔진 × 국가 | |
| 반복 | 같은 셀을 여러 번 물은 것 | |
| 후보군 · 최종 선택 | 답변이 고려한 브랜드 · 차종 목록 · 그중 최종 1순위로 고른 것 | 후보군 · 최종 선택(1순위) |

지표 이름(AI 노출률, AI 점유율, Top1 ACR 등)과 정의는 [metric-definitions.md](../service/metric-definitions.md)에 있다.
