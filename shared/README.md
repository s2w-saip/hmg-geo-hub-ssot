# shared

모든 파트가 공통으로 참조하는 문서. 담당: 전원

## 대전제

**SSOT로 관리하는 모든 문서는 내용을 명확하게 전달할 수 있는 수준에서 가장 짧고 간결하게 정리된 문서로 가공해 넣는다.**

## 여기에 두는 것

다른 파트가 읽어야 일할 수 있는 내용을 둔다. 한 파트만 읽는 내용은 그 파트 폴더에 둔다.

- 전체 구조: 단계, 담당, 데이터 흐름
- 팀 간 데이터 계약: Bronze 응답 원문(계약 1: 앤써 → 분석), Silver 추출 결과 OBT(계약 2: 분석 → 서비스), 프롬프트·기준정보 원본(서비스 → 앤써: 프롬프트·측정 설정, 서비스 → 분석: 분석 기준정보, API로 읽음)
- 용어
- 운영 원칙
- URL 목록: 저장소, 서비스 주소, 프롬프트·기준정보 API, 레거시 프로젝트
