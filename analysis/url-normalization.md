# URL 정규화

인용 URL과 등록 URL(소유 URL · 타겟 URL)을 같은 규칙으로 바꿔 비교한다. 정규화는 분석이 하고, BFF는 그 결과(자사 범위 키 · 페이지 키)로 자사 · 타겟을 판정한다.

## 비교용 주소 두 가지

| 주소 | 쓰는 곳 | 쿼리 |
|---|---|---|
| 자사 범위 키 | 자사 범위 판정: 05 Website, 06, 08의 자사 조건 | 전부 지운다 |
| 페이지 키 | 타겟 비교: 07, 08, 06의 타겟 예외 | 아래 규칙대로 남긴다 |

05 Global은 URL이 아니라 출처 카테고리(공식 (HMG))로 판정한다.

## 규칙

| 처리 | 규칙 |
|---|---|
| 원 URL | 그대로 둔다. 수집이 준 최종 도착 URL(`final_url`)도 함께 둔다 |
| 대소문자 | 스킴 · 호스트만 소문자. 경로 · 쿼리는 그대로 둔다. 대소문자 무관이 확인된 사이트만 정책 표로 합친다 |
| 스킴 · `www.` · 끝 `/` | 지운다 |
| 형식 정리 | 표준 URL 파서(WHATWG)로 기본 포트 · `/../` · 국제화 도메인을 정리한다 |
| 퍼센트 인코딩 | 비예약 문자만 푼다(`%7E` → `~`). `%2F` · `%26` 같은 구분자는 두고, 16진수는 대문자로 맞춘다 |
| `#` 뒤 | 지운다. `#/…`로 화면을 바꾸는 사이트만 남긴다 |
| 추적 키 | 확인한 추적 키만 지운다. 목록은 S2W가 관리한다 |
| 페이지를 정하는 쿼리 | 남긴다(`id`, `model`, `file_id` 등). 중복 키와 순서도 그대로 둔다 |
| 쿼리 정렬 | 순서가 무관함이 확인된 사이트 · 키만 이름순으로 정렬한다 |
| 감싼 주소 | `google.com/url?q=…`는 안쪽 URL을 꺼낸다. 풀 수 없는 토큰은 최종 도착 URL로 판정한다 |
| 리다이렉트 · 별칭 | 최종 도착 URL이나 canonical로 같은 페이지임이 확인된 주소만 별칭 표에 올려 합친다. 홈 · 로그인 · 동의 화면에 도착한 경우는 근거로 쓰지 않는다 |
| 깨진 URL | 로직으로 복원한다. 아래 '깨진 URL 복원' |

정책 표(대소문자 · 추적 키 · 쿼리 정렬 · `#/` · 별칭)에는 근거와 적용 버전을 함께 남긴다.

## 깨진 URL 복원

수집기가 원문의 마크다운 링크 `[주소](주소)`를 `주소](주소`로 잘라 저장한 값이다. 운영 DB(2026-06 ~ 11월)에 342행이 있고, 모두 Gemini 본문 링크다.

1. `](` 뒤쪽을 링크 주소로 쓴다. 마크다운에서는 `( )` 안이 실제 링크다.
2. 같은 답변에 같은 주소가 정상으로 이미 저장돼 있고 원문에 링크가 한 번뿐이면, 수집 중복이므로 1건만 센다.
3. 답변 원문에서 그 링크를 찾지 못하면 미판정으로 표시한다.

원 값 · 복원 값 · 사유를 함께 남긴다.

| 저장된 값 | 복원 |
|---|---|
| `https://doi.org/10.3390/su11061611](https://doi.org/10.3390/su11061611` | `https://doi.org/10.3390/su11061611` |
| `https://www.hyundai.com/kr](https://www.hyundai.com/kr/ko/e` | `https://www.hyundai.com/kr/ko/e` |

## 예

| 입력 | 결과 |
|---|---|
| `/view?articleId=AbC` · `/view?articleId=abc` | 다른 키(대소문자 무관이 확인된 사이트만 합침) |
| `HYUNDAI.com/in/en` · `hyundai.com/in/en` | 같은 키 |
| `https://example.com:443/a` · `https://example.com/a` | 같은 키 |
| `?model=5&trim=long` · `?trim=long&model=5` | 순서 무관이 확인된 사이트만 같은 키 |
| `?model=5` · `?model=6` | 페이지 키는 다름, 자사 범위 키는 같음 |
| `/old-spec` → `/spec`으로 이동 | 최종 도착 URL로 확인되면 같은 페이지 |
| `google.com/url?q=https://hyundai.com/…` | `hyundai.com/…`로 판정 |

## 규칙이 바뀌면

- 등록 base · 타겟 URL도 같은 규칙으로 다시 만든다.
- 새 세대로 다시 계산하고, 이전 세대의 값은 그대로 둔다.
- 증감은 같은 세대 안에서만 계산한다.
