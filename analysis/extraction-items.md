# 추출 항목 정의

한국어 · 영어 답변은 그대로 추출한다. 다른 언어는 영어로 번역한 뒤 같은 기준으로 추출한다.

## 분석 상태

답변마다 분석이 끝났는지 남긴다. 값: 분석 완료 · 분석 실패(분석 공백).

## 엔티티 → 브랜드 매핑

답변에서 찾은 엔티티(브랜드 · 차종)를 KG의 관계에 맞춰 브랜드에 매핑한다. 노출률 · 점유율 · 우선 노출도는 이 브랜드로 계산한다.

| 엔티티 | 매핑 | 예 |
|---|---|---|
| 브랜드 | 그 브랜드 | Kia → 기아 |
| 차종 | 차종이 속한 브랜드 | K5 → 기아, Camry → Toyota |

- 엔티티는 KG에 등록된 이름 · 별칭만 찾는다.
- 원문 위치가 겹치는 이름은 1건으로 남긴다. 예: Hyundai Elantra · Elantra SE · Elantra.
- 숫자 · 규격 · 일반어는 엔티티가 아니다. 예: 타이어 규격 `285/45 R21`의 45.

### 애매한 이름

일반어 · 숫자와 겹치는 이름(Soul, Pride, Stellar, 45 등)은 KG에 '애매한 이름'으로 표시하고, 아래 조건이 맞을 때만 엔티티로 인정한다.

| 조건 | 예 | 판정 |
|---|---|---|
| 바로 앞에 소속 브랜드가 붙음 | "Kia Soul" | 엔티티 |
| 같은 문장 · 항목에 같은 브랜드나 그 브랜드의 차종이 나옴 | "Kia는 Soul과 Seltos를…" | 엔티티 |
| 연식 · 트림 · 파워트레인이 붙음 | "2024 Soul EV" | 엔티티 |
| 영어 문장 중간의 소문자 | "a soul of the brand" | 아님 |
| 규격 · 단위 안의 숫자 | `285/45 R21`, `45 km` | 아님 |

어느 조건에도 맞지 않으면 미판정으로 두고 세지 않는다.

기준정보: KG(이름 · 별칭, 엔티티 종류(브랜드 · 차종), 차종 → 브랜드 관계)

결과(언급마다): 원문 표현 · 위치 · 문장, 엔티티, 매핑된 브랜드

## 언급 순위

담당: @신민철

AI 우선 노출도와 Top 3 노출 비율에 쓴다. 답변의 순위 목록에서 브랜드가 몇 번째 항목으로 제시됐는지다.

1. 답변에서 목록과 항목을 나눈다.
2. 목록마다 순위 목록인지 판정한다(AI). 이용 절차 · 장점 나열 같은 목록은 순위를 매기지 않는다.
3. 항목의 엔티티를 브랜드에 매핑한다. 같은 항목에 같은 브랜드가 여러 번 나오면 1건으로 본다.
4. 항목의 원문 순번을 그 브랜드의 순위로 쓴다. 브랜드를 묶어도 번호를 새로 매기지 않는다.

- 순위 목록이 없는 답변은 순위가 없다.
- 지표에는 답변마다 자사 대표 순위 1개만 들어간다. 고르는 기준은 정할 것(@신민철).

| 원문 | 순위 |
|---|---|
| "1. Kia Telluride … 2. Hyundai Palisade … 3. Toyota Grand Highlander" | Kia 1, Hyundai 2, Toyota 3 |
| "1. 기아 공식 홈페이지 접속 2. 차량 선택 3. 구동 방식 및 트림 선택" | 이용 절차라 순위 없음 |

## 언급 유형

담당: @신민철

초안이다. 브랜드 · 차종이 답변에 나온 방식을 언급마다 하나 정한다.

| 유형 | 정의 | 예 | 아닌 예 |
|---|---|---|---|
| 최종 선택 | 여러 후보 중 답변이 최종 하나로 고른 것 | "딱 하나라면 투싼보다 EV6를 고르겠습니다." → EV6 | 같은 문장의 투싼(비교) |
| 추천 | 답변이 사용자에게 권하는 것 | "가족용 SUV라면 Telluride를 추천합니다." | "1. 기아 공식 홈페이지 접속" 같은 이용 절차 번호 |
| 비교 | 다른 브랜드 · 차종과 견주는 대상으로 나온 것 | "투싼보다 EV6" → 투싼 | 순서만 나열한 목록 |
| 정의 | 그 브랜드 · 차종이 무엇인지 설명 · 소개한 것 | "Genesis는 현대자동차그룹의 고급 브랜드다." | 평가가 들어간 설명(감성으로 본다) |
| 단순 언급 | 위 넷에 해당하지 않고 이름만 나온 것 | "Toyota, BMW 등 여러 브랜드가 있다." | |

- 여럿에 해당하면 위 표의 순서(최종 선택 → 추천 → 비교 → 정의 → 단순 언급)로 앞의 것을 고른다.
- 그 언급이 있는 문장으로 판단한다. 답변의 나머지는 무엇을 가리키는지 확인할 때만 본다.
- 최종 선택은 답변이 실제로 하나를 골랐을 때만이다. 후보를 여럿 나열하면 추천이다.

- 같은 인용 번호로 두 번 저장된 것(ChatGPT의 원주소와 `?utm_source=chatgpt.com` 주소)은 1건으로 남긴다.
- 같은 페이지를 다른 문장 · 위치에서 여러 번 인용한 것은 각각 남긴다.
