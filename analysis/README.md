# analysis

분석 모듈 이해를 위한 문서. 담당: 신민철, 박보규

## 대전제

**SSOT로 관리하는 모든 문서는 내용을 명확하게 전달할 수 있는 수준에서 가장 짧고 간결하게 정리된 문서로 가공해 넣는다.**

  - AI 없이 하는 항목: 분석 상태, 엔티티 → 브랜드 매핑, 인용 목록, URL 정규화([url-normalization.md](url-normalization.md))
