# Non-AI 처리

AI 없이 사전 · 규칙으로 하는 작업이다. 로직은 git 커밋 + 태그로 관리한다([rule-versions.md](rule-versions.md)).

| 작업 | 추출 항목 | 입력 | 출력 |
|---|---|---|---|
| 분석 상태 기록 | 분석 상태 | 답변별 분석 결과 | 분석 완료 · 분석 실패 |
| 엔티티 찾기 · 브랜드 매핑 | 엔티티 → 브랜드 매핑 | 답변 본문, KG | 언급마다 원문 표현 · 위치 · 문장, 엔티티, 매핑된 브랜드 |
| 애매한 이름 확인 | 엔티티 → 브랜드 매핑 | KG에서 '애매한 이름'으로 표시된 표현과 그 문장 · 항목 | 엔티티 인정 · 아님 · 미판정 |
| 원문 순번 붙이기 | 언급 순위 | 마크다운 구조화 결과, 순위 목록 판정 결과, 매핑 결과 | 항목별 원문 순번과 브랜드 |
| 인용 목록 만들기 | 인용 목록 | 수집 결과의 인용 · 본문 링크 | 인용마다 원 URL, 최종 도착 URL, 인용 번호, 인용 구절, 원소 순번 |
| 깨진 URL 복원 | 인용 목록 | `주소](주소`로 저장된 URL | 복원한 URL |
| URL 정규화 | 인용 목록 | 인용 URL, 등록 URL(소유 URL · 타겟 URL) | 자사 범위 키, 페이지 키 |

판정 기준은 [추출 항목 정의](extraction-items.md)를, 깨진 URL 복원과 URL 정규화 규칙은 [URL 정규화](url-normalization.md)를 따른다.
