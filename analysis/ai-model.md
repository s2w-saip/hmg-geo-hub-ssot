# AI 모델

담당: @신민철

AI가 필요한 추출 항목의 작업이다. 모델은 작업마다 환경변수로 지정한다([rule-versions.md](rule-versions.md)).

| 작업 | 추출 항목 | 입력 | 출력 |
|---|---|---|---|
| 마크다운 구조화 | 언급 순위, 엔티티 → 브랜드 매핑 | 답변 본문 | 제목 · 목록 · 항목 · 표 구조 |
| 문장 나누기 | 엔티티 → 브랜드 매핑, 언급 유형, 감성 | 답변 본문 | 문장 목록(원문 위치) |
| 순위 목록 판정 | 언급 순위 | 답변의 목록 하나 | 순위 목록인지(예 · 아니오) |
| 언급 유형 판정 | 언급 유형 | 언급과 그 언급이 있는 문장 | 유형 1개 |
| 감성 판정 | 감성 | 답변 본문 | 대상 · 범주마다 감정 하나와 근거 |
| ACR 판정 | ACR 후보군 · 최종 선택 | 답변 본문 | 후보(원문 순서), 최종 선택 |
| 출처 카테고리 판정 | 출처 카테고리 | 아직 분류되지 않은 새 출처 | 카테고리 1개(13개 중) |
| 다른 언어 번역 | 전체 | 한국어 · 영어가 아닌 답변 본문 | 영어 번역문 |

판정 기준은 [추출 항목 정의](extraction-items.md)를 따른다.
