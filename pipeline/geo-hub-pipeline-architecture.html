GEO HUB 파이프라인 아키텍처

Backend가 프로젝트별 스케줄로 수집을 요청하면, 파이프라인이 수집 완료된 응답을 회차와 상관없이 가져와 Bronze에 Raw로 쌓고, Silver의 분석 모듈을 거쳐 OBT로 만듭니다. Backend는 OBT와 회차 단위 테이블 2개만 조회합니다.

전체 흐름

맨 위는 수집 요청, 가운데 줄은 데이터 흐름, 아랫줄은 회차 ID 기준으로 관리하는 테이블입니다. 각 층 아래에 row 단위를 적었습니다.

  • 원천
  • Bronze
  • Silver · 규칙 기반 모듈
  • AI 모듈 (LLM 호출)
  • Backend에 전달하는 테이블
  • Backend · 수집 요청 · 관리
  • Backend · BFF · 대시보드
  • 우리 파트 아님

모듈 = 플러그인 · Handler Output이 OBT 컬럼이 되는 구조

모듈마다 Handler와 Output 스키마를 정의합니다. Runner에 끼우고 빼는 구조라 개발자별로 모듈을 따로 개발해 붙일 수 있고, 각 모듈의 Output은 정의된 OBT 컬럼에 저장됩니다.

M모듈 하나의 구성

handler.py

입력 SQL · 출력 테이블
